# Punktiq Roadmap

The roadmap prioritises validation and trustworthy foundations over adding a large number of features.

## Current prototype

- mobile-first onboarding and mock account flow;
- academic profile setup;
- Simon-led dashboard;
- study library and focused reader;
- check questions and completion feedback;
- in-browser SQL practice;
- private notes, goals, daily XP, and streak state;
- cohort/course/programme/friends leaderboard scopes;
- Simon moods and cosmetics;
- admin overview with season and integrity concepts;
- local persistence, PWA metadata, and deployment configuration.

## Next: make the prototype testable

- create a fully synthetic, redistributable demo-content pack;
- add a sanitised interface capture set and short demo video;
- add tests for attempts, completion, duplicate rewards, streaks, goals, and rank recalculation;
- complete keyboard, contrast, reduced-motion, and screen-reader checks;
- document product assumptions and structured usability-test tasks;
- validate whether Simon's recommendation reduces decision friction.

## Next: establish production boundaries

- design real authentication and authorisation;
- move reward-critical decisions to a server boundary;
- define a minimal backend and data-retention model;
- design leaderboard opt-in/opt-out and visibility controls;
- define content publishing, review, attribution, and takedown workflows;
- design integrity review, appeal, and audit processes;
- add observability without collecting unnecessary student data.

## Later: validate with people and institutions

- run small, consent-based usability sessions;
- test whether verified checks improve study follow-through;
- test daily caps and reward pacing for unintended behaviour;
- evaluate cohort comparison effects on different learners;
- explore institutional integration only with explicit permission and governance;
- evaluate desktop widgets and notifications after the core loop proves useful.

## Explicitly not promised

- official KdG adoption;
- production launch dates;
- real-user or engagement metrics;
- broad AI tutoring features;
- an infinite social feed;
- a complete administration platform before real operational needs are known.
