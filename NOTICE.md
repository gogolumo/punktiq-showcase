# Punktiq Showcase Notice

This repository is a portfolio case study for Punktiq, an independent interactive study-companion prototype created by Bohdan Dron.

## What is included

- a high-level product overview;
- a non-sensitive architecture summary;
- an original portfolio cover;
- one rasterised preview of the Simon mascot;
- an evidence-based roadmap and project-status statement.

## What is deliberately excluded

- application source code and configuration;
- Git history from the private development repository;
- course materials, cheat-sheet bodies, and question banks;
- editable mascot and brand source files;
- credentials, secrets, personal email addresses, and private documents;
- real student identities or activity data.

Any interface captures added later must use fictional screen names and sanitised content. They must not reveal private accounts, real classmates, assessment questions, or protected course material.

Punktiq is not an official KdG product and is not affiliated with or endorsed by Karel de Grote University of Applied Sciences and Arts.

No open-source licence is granted for this showcase. The absence of application source code and an open licence does not make the underlying product idea impossible to reproduce independently; it simply means no permission is given to reuse the copyrighted materials published here.
